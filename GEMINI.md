# Aegis Project Workspace Rules

Always adhere to the project conventions and security constraints when developing in this repository.

1. **Aegis Conventions:** Always follow the rules defined in `.agents/plugins/aegis-dev/rules/aegis-conventions.md`.
2. **Sandbox Restrictions:** Do not relax constraints on the Docker sandbox (`backend/runner/Dockerfile.sandbox`).
3. **Agent Contracts:** Any modifications to agent output schemas must be reflected across backend and frontend contracts simultaneously.
